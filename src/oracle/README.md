# Oracle

Oracle is a knowledge platform for understanding how the world perceives your website.

Unlike traditional SEO tools, Oracle separates the collection of evidence from the interpretation of that evidence.

Oracle first learns what a website is trying to communicate, then observes how search engines, AI systems, and other sources perceive that communication. Finally, it helps identify opportunities to improve the alignment between those two perspectives.

---

## Components

Oracle is composed of four primary subsystems.

### Discovery

Learns the structure and content of the website.

- Reads sitemaps
- Discovers pages
- Extracts metadata
- Generates candidate queries
- Populates the Oracle database

### Monitor

Observes external sources.

Examples include:

- Google Organic
- Google AI Overview
- Bing
- Perplexity
- ChatGPT
- Gemini

Each monitor records observations without interpreting them.

### Dashboard

Provides the user interface for Oracle.

Dashboard allows users to:

- Explore observations
- Review and edit queries
- Compare sources
- Configure scoring models
- Analyze historical trends

### Oracle

The intelligence layer.

Oracle analyzes historical observations and recommends actions that improve the visibility and discoverability of the website.
